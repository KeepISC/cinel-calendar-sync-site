A public calendar.

CINEL Calendar Sync is a Python application that automatically retrieves training schedules from the CINEL platform and synchronizes them with a publicly accessible Google Calendar.

The calendar is intended primarily for classmates, but anyone with its public link can view its events. Events may also be discoverable more broadly depending on Google Calendar's public-sharing settings.

This is an independently maintained calendar, not an official CINEL service.

CINEL schedules→ Python script→ Google Calendar

How synchronization works

The script uses the calendar owner's personal CINEL credentials to retrieve training schedules and the owner's Google OAuth authorization to access the Google Calendar API.

  • Creates events for upcoming training sessions.
  • Updates existing events when session details change.
  • Deletes previously synchronized events that are no longer in the retrieved schedule.

Calendar events contain class dates, start and end times, course/module names and classroom locations, with classroom-specific colors where configured.

Public events, private credentials

Classmates and other calendar viewers do not need to authenticate with CINEL or authorize Google OAuth. The calendar owner controls public sharing and can disable it.

Google Calendar data is accessed and modified only for schedule synchronization. The owner's CINEL credentials and OAuth tokens are kept private, stored locally or as protected GitHub Actions secrets, and are never intentionally published in calendar events or shared with viewers.

The script can run locally, or GitHub Actions may execute synchronization automatically. This website explains the application; it does not run synchronization or request Google authorization.

Read the Privacy Policy for details about access, storage, sharing and revoking authorization.
